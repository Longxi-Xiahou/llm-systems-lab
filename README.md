# LLM Systems Lab

A hands-on learning and engineering project focused on LLM systems.

## Topics

- Transformer and Attention
- KV Cache
- GQA / MQA
- FlashAttention
- Quantization
- LLM Inference
- GPU / CUDA
- Triton
- Inference Scheduling
- Mixture of Experts
- Distributed Systems
- vLLM / SGLang / TensorRT-LLM

## Environment

- Python 3.12
- PyTorch
- CUDA
- NVIDIA RTX PRO 5000 Blackwell
